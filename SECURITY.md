# Security

## What this app can touch

The player runs entirely in your browser. It reads the music folder you choose and keeps song tags and small artwork thumbnails in the browser's own storage on your computer. It has no server, no accounts, and sends none of this anywhere.

## Reporting a problem

Please report security problems privately, not in a public issue.

Use **Report a vulnerability** under this repository's **Security** tab (GitHub's private vulnerability reporting). Include what you found, how to reproduce it, and the browser and version you used.

You should get a reply within a week. Once a fix is released you will be credited, unless you prefer not to be.

## Supported versions

Only the latest version on the `main` branch, which is what the hosted site runs, receives fixes.
