# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. It applies to everyone taking part in the project's issues, pull requests and discussions.

In short: be respectful, assume good intent, accept constructive criticism gracefully, and keep the focus on what is best for the project and the people in it. Harassment, insults, sexualised language or attention, and publishing someone's private information are not acceptable.

## Reporting

If something happens that you think breaks this code of conduct, report it privately to the maintainer through the contact options on their GitHub profile. Reports are kept confidential.

The maintainer will review every report and may remove comments, close or lock threads, or block a participant, following the enforcement guidelines in the Contributor Covenant.
